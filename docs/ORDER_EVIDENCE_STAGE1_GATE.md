Assess production growth and need for a concurrent index via a separate migration plan, not an automatic deployment.

This is inherited from the active release, not evidence that the new endpoint caused it. Stage 1 is NOT ready to deploy until the owner agrees on a narrow pool-error recovery fix, the fix is implemented and reviewed, and an isolated test proves the process survives database loss, returns a safe error, then recovers after reconnect.

# Отчёт о редизайне главной OZELIF

## Что изменено

- С нуля собрана React + TypeScript + Vite-реализация, поскольку исходный репозиторий был пуст.
- Новая структура: прозрачный/плотный header, полноэкранный hero, асимметричный каталог, новые поступления, редакционные доказательства, швейное производство, оптовый блок, первая скидка, шоурум/контакты/форма, компактный SEO-блок и footer.
- Добавлены дизайн-токены, адаптив от 320 px, мобильное меню, видимые focus-состояния, семантика, reduced motion, lazy loading и reveal-анимации.
- Добавлены title, description, canonical, Open Graph, Twitter Card, Organization JSON-LD, robots и sitemap.
- CTA и внутренние ссылки сохраняют маршруты действующего сайта через абсолютный домен `ozelifkoja.ru`.

## Контент и редактура

С действующего сайта взяты категории, 1000 вариантов, работа с 2011 года, розница/опт, география, шоурум, фабричное представительство, оптовый минимум, первая скидка, контакты и реквизиты. Длинные тексты о компании, SEO и опте сокращены; неподтверждённые превосходные степени удалены. Реальные отзывы не копировались — сохранена ссылка на Яндекс Карты.

## Изображения

Все фотографии взяты с CDN действующего сайта OZELIF и сохранены локально. Полный перечень, исходные URL и размеры находятся в `docs/homepage-content-audit.md`. Hero 500×749 и карточка новых поступлений 396×396 требуют ручной замены на оригиналы высокого разрешения перед публикацией на большой desktop.

## Противоречия

- Щёлковское шоссе, 5с1 против Краснобогатырской улицы, 24. В структурированных данных использована Краснобогатырская, 24, потому что её подтверждают отдельная страница контактов и footer; предупреждение видимо в интерфейсе до ручного подтверждения.
- «13 лет» против «с 2011 года» и текущего 2026 года. Оставлена дата 2011 без вычисляемого счётчика.
- Несколько WhatsApp-номеров, включая неподписанный `+7 925 344-73-43`. Основной CTA ведёт к Эмилии на подтверждённый номер `+7 903 370-78-54`.

## Форма

Форма валидирует имя и телефон, блокирует повторную отправку, показывает loading/success/error и содержит согласие. Для безопасного подключения backend предусмотрен `VITE_FORM_ENDPOINT`. Без переменной форма работает в демонстрационном режиме; идентификаторы внутренних сервисов Tilda намеренно не копировались. Перед production необходимо указать endpoint либо адаптер существующей Tilda-формы.

## Ручная проверка перед публикацией

1. Подтвердить адрес шоурума и после этого удалить предупреждение из интерфейса.
2. Уточнить основной WhatsApp и назначение номера `+7 925 344-73-43`.
3. Подключить реальный endpoint формы и проверить уведомления/CRM.
4. Заменить hero и изображение новых поступлений на большие оригиналы.
5. Проверить фактические страницы `/new`, `/info`, `/about`, `/pdf` на production-домене перед публикацией.
6. Проверить актуальность акции 500 рублей непосредственно перед публикацией.

## Запуск и проверки

```bash
npm run dev
npm run lint
npm run typecheck
npm run test
npm run build
```
